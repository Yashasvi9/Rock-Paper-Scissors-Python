# Rock Paper Scissors – Python 🎮

A beginner-friendly Python implementation of the classic Rock Paper Scissors game where the user plays against the computer in the console.

---

## 📌 Description
This project is built using basic Python concepts such as user input handling, loops, functions, and random choice selection.  
It is designed for beginners who want to practice core programming fundamentals in a fun and interactive way.

---

## ✨ Features
- User vs Computer gameplay
- Randomized computer choices
- Clear win, lose, and draw logic
- Simple and readable code
- Beginner-friendly project structure

---

## 🛠️ Technologies Used
- Python 3
- Built-in `random` module

---

## ▶️ How to Run the Game
1. Make sure Python is installed on your system
2. Clone the repository or download the files
3. Run the following command in your terminal:

```bash
python Rock-Paper-Scissors.py
