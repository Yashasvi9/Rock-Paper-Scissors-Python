# Rock Paper Scissors – Python 🎮

A beginner-friendly Python implementation of the classic Rock Paper Scissors game where the user plays against the computer. This repository contains **two versions** of the game:  

- **Main branch** – Full gameplay, multiple rounds (`Rock-Paper-Scissors.py`)  
- **V1 branch** – One-time play, single round (`Rock-Paper-Scissors2.py`)  

---

## 📌 Description
This project is designed for beginners to practice Python concepts like loops, functions, user input handling, and random choice selection.  

| Branch | File Name | Gameplay |
|--------|-----------|----------|
| main   | `Rock-Paper-Scissors.py` | Play multiple rounds against the computer |
| V1     | `Rock-Paper-Scissors2.py` | Play only a single round |

---

## ✨ Features

### Main Branch – Full Version
- User vs Computer gameplay  
- Multiple rounds until the user quits  
- Clear win, lose, and draw logic  
- Beginner-friendly code structure  

### V1 Branch – One-Time Play
- Single-round gameplay only  
- Randomized computer choice  
- Simple, readable code  

---

## 🛠️ Technologies Used
- Python 3  
- Built-in `random` module
